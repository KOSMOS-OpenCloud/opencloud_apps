# TODO: 412-Fehlermeldung bei Zuweisung (2026-09-23)

## Problem

Beim Verschieben einer Datei im Posteingang (MOVE) zeigt die App bei HTTP 412
nur "Zuweisung fehlgeschlagen: 412 Unknown Error" an. Die eigentliche Ursache
(Datei existiert bereits im Ziel) ist für den User nicht erkennbar.

## Ursache

`reva/internal/http/services/owncloud/ocdav/move.go:263` gibt 412 zurück,
wenn das Ziel bereits existiert und kein `Overwrite: T` gesetzt ist.
Die Posteingang-App sendet MOVE ohne Overwrite (korrektes Verhalten),
übersetzt den 412 aber nicht in eine sinnvolle Meldung.

## Fix

- [x] `apps/posteingang/src/App.vue`: 412 → "Datei existiert bereits im Ziel"

- [ ] **Test**: Zuweisung auf bereits existente Datei → klare Meldung
